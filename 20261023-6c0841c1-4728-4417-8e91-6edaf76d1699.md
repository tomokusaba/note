## GitHub Changelog

- **[Meta API endpoints updated for Actions blob storage](https://github.blog/changelog/2026-10-22-meta-api-endpoints-updated-for-actions-blob-storage)**
  - GitHub Actions のログやジョブサマリー用ストレージの新しいホスト範囲が Meta API に追加されました。個別ホストを許可リストに登録している組織は、追加しないとジョブサマリーやログに影響する可能性があります。
  - `productionresultssa*.blob.core.windows.net` を許可済みの場合、追加対応は不要です。

- **[Public monitoring now available with data residency](https://github.blog/changelog/2026-10-22-public-monitoring-now-available-with-data-residency)**
  - GitHub Enterprise Cloud with data residency で、公開コミットを監視して漏えいした認証情報を検知する機能がパブリックプレビューになりました。
  - 利用には GitHub Advanced Security または GitHub Secret Protection のライセンスが必要です。確認済みドメインで照合し、アラートは指定リージョン内に届けられます。
