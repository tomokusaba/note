## GitHub Changelog の重要更新

- 参考: [GitHub Changelog](https://github.blog/changelog/)


- **[Copilot budget increase requests are generally available](https://github.blog/changelog/2026-09-16-copilot-budget-increase-requests-are-generally-available)**
  - Copilot の AI credits が枯渇したメンバーが、予算増額のリクエストをその場で送信できるようになりました。
  - Org / Enterprise の請求管理者がリクエストを承認・調整・拒否でき、利用制限をすばやく解除できるようになっています。
  - GitHub Copilot Business / Enterprise の従量課金利用者にとって、運用面の影響が大きい更新です。

- **[Code scanning AI Scan no longer requires CodeQL default setup](https://github.blog/changelog/2026-09-16-code-scanning-ai-scan-no-longer-requires-codeql-default-setup)**
  - AI Scan for pull requests が、CodeQL default setup が有効でなくても利用できるようになりました。
  - repository のセキュリティ検出が拡張され、GitHub Advanced Security の導入ハードルが下がります。
  - 対象リポジトリでの脆弱性検出の適用範囲が広がるため、実務上の価値は高いです。

- **[Enforce GitHub Advanced Security configurations](https://github.blog/changelog/2026-09-15-enforce-github-advanced-security-configurations)**
  - Enterprise 管理者が GitHub Advanced Security の設定を強制できるようになりました。
  - Organization / Repository 管理者による設定の上書きを制限できるため、企業向けセキュリティポリシーの一貫性が高まります。
  - 大規模組織での governance 強化に直結する更新です.
