## GitHub Changelog

- **[pull_request_target blocked by default December 2](https://github.blog/changelog/2026-11-02-pull_request_target-blocked-by-default-december-2)**
  - 2026年12月2日から、GitHub Actionsは公開リポジトリで `pull_request_target` を既定でブロックします。必要なワークフローでは、適用される Actions event policy で明示的に許可してください。
  - 事前の影響確認には Insights を利用できます。11月9日と16日には一時的な適用期間が予定されており、非公開・内部リポジトリは対象外です。

- **[Security risk assessments include repository protection status](https://github.blog/changelog/2026-11-02-security-risk-assessments-include-repository-protection-status)**
  - Code Security と Secret Security のリスク評価で、検出結果が保護済み・未保護のどちらのリポジトリにあるかを確認でき、セキュリティ対策の不足箇所を把握しやすくなりました。
  - GitHub Enterprise Cloud と GitHub Team で利用でき、Secret Security の評価は GitHub Enterprise Server 3.24 にも提供予定です。
